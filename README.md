# VXT Signal

Webapp quét toàn sàn Binance: điểm vào/ra Long–Short (chỉ báo VTS), kế hoạch SL/TP theo vùng giá, điểm vào sắp tới, đánh giá bơm/xả của MM, theo dõi cá mập, ví on-chain và funding rate. Chạy trực tiếp qua WebSocket công khai của Binance.

- Mở app: https://tuyentvtkthainguyen.github.io/vxt-signal/
- Cài ra màn hình chính: Android (Chrome) bấm “📲 Cài app”; iPhone (Safari) bấm Chia sẻ → Thêm vào MH chính.

Không thu thập dữ liệu người dùng. Khóa API (nếu nhập) chỉ lưu trong trình duyệt của bạn. Đây là công cụ hỗ trợ phân tích, không phải lời khuyên đầu tư.
